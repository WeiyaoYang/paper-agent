更新：2026-10-27。日常入口推荐 [桌面工作台](desktop.md)，原终端 chat 保留；目标和运行流程分别见 [业务报告](business-results.md)、[完整流程](workflow.md)。桌面复用现有流程控制器，增加启动页、聊天/文件夹、多行输入、PDF 选择和拖入、确认按钮及后台任务状态。同一时间执行一个操作，不支持强制中断在途模型调用。源码分发增加安装/初始化/导出脚本、空白资料模板、通用公开素材，详见 [发布说明](distribution.md)。

## 已实现

| 能力 | 当前效果 |
|---|---|
| 材料准备 | 本地 PDF 归档、去重、Docling/pdfplumber 解析、页码与内容块、版本和只读检查 |
| 初始规划 | 模型读取上下文，按需补读或澄清，提交 planning 片段 |
| 统一交互 | 独立桌面窗口与原终端共用学习流程；桌面支持聊天管理、文件夹、PDF 导入、多行回答和保存/结束按钮 |
| 自主调度 | 模型依据计划、真实产物和反馈选择五种学习行为，不固定轮流执行 |
| 行为 | 阅读、探讨、问答、知识记录；知识点和笔记关联，名称/唯一别名复用 |
| 理解验证 | 必经提问、等待真实回答、逐题反馈、参考答案和总体判断 |
| 结果与重规划 | result 保存是否达标、reason、实际变化；未通过形成原目标不变的下一版规划 |
| 结束 | 通过后询问结束/继续；明确提前退出不算通过 |
| 运行保护 | 结构和引用校验、进程锁、调用次数预算、快照和错误现场，不自动重放失败请求 |

画像与框架只读。正式数据为文件存储，旧数据库仅留迁移备份。没有画像修改、框架修改、RAG 向量索引、全局美元预算或已有正式知识修改接口。

## 验证证据

- Windows x64 便携 EXE 已构建，本机在清空 Python 环境变量后通过界面、PDF 导入解析、模拟学习保存恢复和 Docling 实际解析检查。源码测试增加到 56 项。ZIP 使用白名单排除数据、密钥、缓存和自检产物；尚未在另一台干净电脑复测。详见 [便携构建验证](portable-verification.md)。

- 54 项离线测试通过，使用合成材料及模拟模型，不依赖作者个人数据。含规划 → 阅读 → 验证未通过 → 新规划 → 补缺 → 再验证通过 → 结束，及桌面、首次初始化和资料保护测试。
- 个人实例中的 π₀ 论文不随源码分发，新用户自行导入论文。
- 用户此前已通过终端完成真实 API 的规划、阅读、提问、验证、复盘保存与结束确认；期间修正了验证候选改写目标造成的校验失败。桌面整条真实 API 路径尚未另外验证。
- 干净导出副本已通过初始化、54 项离线测试及无私人配图/论文/密钥的默认界面检查。本轮无付费 API 调用；尚未在另一台电脑完整联网安装。

## 实际限制

单篇论文、单用户、本地使用；统一 chat 有写入锁，单项排查命令不可与其并发。截断、失败或不确定中断保留现场，不自动重试；暂无现场自动修复和预算增加入口。

按记录摘要选行为，必要时读取本次允许的完整记录；不是任意文件访问或通用资料检索。模型解释、reason 和评分可能出错，引用检查只证明原文位置存在。公式、图像语义、扫描件和复杂表格有提取限制。

UUID 编号保留，分类仍用原始框架文字，未实现复杂语义去重、知识图谱和长期能力评估。批量记录没有断电级事务保证。
