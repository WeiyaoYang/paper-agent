# 桌面工作台

双击桌面“Agent 工作台”快捷方式，或项目内 `启动工作台.vbs`，打开独立窗口。运行使用项目 `.venv` 的 pythonw，模型、解析缓存和临时目录位于项目内（本机项目在 D 盘）。开发环境安装：`uv pip install --python .venv/Scripts/python.exe '.[models,desktop]'`。

启动页选择 Paper Agent。工作页左边管理文件夹和聊天，右边显示对话。点击新聊天，选择论文并输入学习要求；Enter 换行，Ctrl+Enter 或发送按钮提交。一次聊天对应一次学习，支持多轮验证和重新规划。

点击“导入 PDF”或把本地 PDF 拖入窗口，文件按哈希去重并复制至 `data/papers/paper_ID.pdf`；新导入论文的 source 保存原始绝对路径。已有重复论文保留原登记来源。导入本身不调用大模型，新聊天首次使用未解析的 PDF 时调用 Docling，随后才发送所需材料、画像和知识框架到 OpenAI 官方 API。解析工具可能下载模型到项目 .cache 目录。

候选记录通过“确认保存”提交；也可输入补充意见继续讨论。“验证并准备结束”请求理解验证，通过后可选择“结束学习”或“继续学习”。错误时保留已有进度，不自动重放可能计费的请求。blocked 状态需要检查运行记录，当前不提供一键修复或增加预算。

右键聊天可重命名、移动到文件夹；右键文件夹可重命名。聊天组织、显示历史保存在 `data/runs/desktop/workspace.json`，不属于十类正式学习信息。正式记录与原来的终端入口共用目录。旧终端会话展示保存的目标、事件、当前问题摘要，历史终端逐轮原始发言仍保留在子行为记录中；新桌面聊天保存连续交互的展示历史。

全工作台同一时间只提交一项操作。模型运行时仍可查看其他聊天、返回启动页；全局状态栏显示后台任务，不会因此结束学习。后台任务完成前不能关闭窗口，避免打断可能计费的请求。空闲关闭后，等待回答的会话可直接继续；明确暂停的会话用恢复按钮继续。运行前后均使用原有进程锁，若终端正在持有锁，界面会拒绝执行；不应与终端同时修改同一数据。

设置菜单目前只有“返回 Agent 选择页”。当前没有删除、云同步、多任务并行、模型配置界面或真正的 token 流式显示；会显示实际模型调用次数和当前操作进度。
