# 本轮代码与文档检查报告

日期：2026-10-22。检查范围是本项目自有源码、测试、结构、指令、配置和说明；不把第三方依赖逐个重新审计。

## 已完成

- 统一 chat 入口及恢复入口，支持多行回答、保存、暂停、状态、主动指定行为、验证后结束与明确提前退出。
- 调度模型按规划、真实记录和用户反馈选择下一行为；执行器提供本次学习记录的受限读取能力。
- 串联验证、结果和失败后的下一版规划，保留 study_id 和全部版本。
- 全会话默认 40 次 API 尝试，上限跨各版累计；失败、中断或已在途请求不自动重放。
- 统一入口提供进程锁，恢复前校验运行状态 Schema。

## 检查中修正的问题

- 原材料 Schema 只有文件而未参与写入：现已接入论文登记和内容保存。
- 导入元信息失败可能留下新 PDF：现会清理该次未登记副本。
- 正常工具响应没有 output_text 被误报：现按真实 function_call 区分。
- 知识点查询截断可能漏掉精确匹配：界面结果有限制，保存去重检查完整匹配集。
- CLI 对损坏结构可能打印未处理异常：补充结构错误和中断处理。
- .gitignore 仍匹配旧 data 路径：改为忽略运行数据，仅保留 data/README.md。
- requirements 中固定 D 盘的 editable 引用：移除，改为单独安装当前项目。
- 删除无调用方的旧 diagnostic.toml；更新所有当前文档，旧开发记录明确作为历史。

## 验证

48 项离线测试通过，覆盖各模块与完整多轮统一会话、暂停恢复、覆盖选择、强制验证、错误状态、预算、进程锁、记录来源和写入失败。另核对 21 个源码文件、9 个测试文件、12 份 Schema、21 份入口及当前说明文档，全部配置、实际论文结构、CLI 帮助和本地链接通过。

测试使用临时目录、模拟模型；本轮未新增付费 API 请求。原四类行为曾真实 API 验证，新的统一组合未实测真实 API。正式数据（不含按任务更新的 data/README.md）在最终验证前后哈希一致，无测试记录遗留。

## 保留的限制

仍按单用户本地使用，不支持单项命令与 chat 并发写入；没有断电级事务或故障自动修复。次数预算不是金额预算。模型的解释和评分、PDF 公式和图片处理能力需要实际使用中继续检验；此报告不把离线测试等同真实模型质量保证。
