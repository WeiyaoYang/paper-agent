# 源码分发说明

## 首次安装与目录

目标是克隆或解压源码后按 README 安装使用，不要求复制作者的文件结构或私人数据。推荐 Windows + uv；安装脚本选择 Python 3.12，在项目中创建虚拟环境。程序、依赖、解析模型缓存、临时目录按项目位置计算。安装位置应可写，不能直接安装到只读目录。当前只验证 Windows 桌面，其他系统尚无桌面发行保证。

`init` 和桌面启动会创建十类结果目录、papers/artifacts/runs/logs，并仅在核心文件缺失时复制 templates 的空白模板。现有画像和框架不覆盖。配置密钥使用桌面首次发送提示或手动复制 `.env.example`；终端需手动配置。编辑画像和框架目前仍通过文件完成，不宣称已有完整 onboarding 编辑器。

## 可以上传什么

上传源码、schemas、behaviors、prompts、通用配置、空白模板、通用 SVG、脚本、测试和文档。不要上传 `.env.local`、data 中实际数据、.venv、.runtime、.cache、tmp、dist 或私人图片。`.gitignore` 用于后续 Git 提交；`release.ps1` 使用显式白名单，避免未初始化 Git 时误打包。

个人图标和插画继续保留在本机 assets/app-icon*、assets/welcome-character*，被排除在公开包外；干净源码自动显示通用书本图标及欢迎页。

## 发布步骤

1. 执行 `scripts/release.ps1`，取得 dist 内的新源码目录和 source.zip。
2. 检查导出内容，确定仓库名称和许可证；目前不自动选定许可证。
3. 在干净源码目录初始化 Git 并推送目标仓库。不要把 dist 放入自身仓库，也不要把外层个人 tools 工作区作为公开根目录。
4. 后续更新应继续同步允许公开的源码，不同步作者数据。已有 Git 历史若曾提交密钥，单加 gitignore 无法抹除历史，需要另外处理。

本轮只整理本机源码及发布包，不创建 GitHub 仓库、不推送、不更改作者现有配置和学习数据。当前项目尚未初始化 Git，因此没有本项目 Git 历史可检查。

## 验证边界

测试使用临时合成材料、模拟模型和空白模板。需检查干净导出目录在不依赖原始 data、私人图片和 API 密钥的情况下完成初始化、默认界面显示、离线完整测试。此检查不等同于在另一台 Windows 电脑完整联网安装；依赖安装与真实 API 可用性取决于用户网络、平台和账号模型权限。
