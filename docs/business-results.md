# 业务结果报告

更新：2026-10-22。本文描述业务职责与当前边界；实际验证范围见 [当前实现](implementation-status.md)。

## 定位与场景

个人论文学习与讨论 Agent：用户指定论文，围绕项目需要理解概念和方法，逐步积累有来源、可关联的知识；中文为主，必要时保留英文术语。不以填满表格代替学习。

核心场景一：新论文进入后，准备材料、澄清目标、规划学习、按实际缺口选择行为并验证理解。

核心场景二：围绕指定论文讨论观点、复用已积累的材料和知识。当前可读取同一次学习的记录并查找知识点；跨全部历史材料的 RAG 检索尚未实现。当前不处理完全不指定论文的通用问题。

## 十类信息

| 顺序 | 信息 | 主要职责 |
|---|---|---|
| 1 | 个人画像 | 背景、偏好、方向、已有依据的掌握状态；学习中只读 |
| 2 | 知识框架 | 分类底图与关系；当前是原始文本，学习中只读 |
| 3 | 学习笔记 | planning：目标、材料、计划；result：目标是否达到、reason、问答依据、其他七类实际变化 |
| 4 | 论文 | 稳定编号、标题、来源、PDF、哈希与解析状态 |
| 5 | 论文内容 | 解析版本、正文、页码、块与坐标、提取限制 |
| 6 | 阅读记录 | 范围、理解重点、材料依据、真实交互及遗留问题 |
| 7 | 问答记录 | 问题、真实回答和反馈；含专门的理解验证记录 |
| 8 | 探讨记录 | 观点、证据、分歧、阶段结论与真实交互 |
| 9 | 知识笔记 | 可复用内容、来源、知识点关联、记录者与验证状态 |
| 10 | 知识点 | 编号、名称、别名、分类及关联 |

十类是正式信息归属，不限制运行状态、候选、日志也有结构。chat 状态或知识候选包不是第十一类正式知识。

## 学习循环

1. 用户指定论文与初步目标；Agent 可帮助澄清，不要求用户先精确理解术语。
2. 准备论文及内容，已有可用版本复用；模型按需读取材料并形成规划。
3. 根据目标、真实交互和产物自主选择行为，用户可覆盖选择；候选审阅后保存。
4. 正常完成前执行理解验证，提出适量问题，等待真实回答，保留参考答案与判断依据。
5. 生成 result。未通过保留结果，围绕原目标形成新版规划，再学习、再验证；通过后询问结束或继续。

暂停保留进度；提前退出记 ended_early，不能标为通过。没有用户真实回答不能生成验证结论；一次通过不证明长期掌握，不修改画像。

## 七种行为

| 行为 | 作用 | 边界 |
|---|---|---|
| reading | 阅读解释指定材料 | 可选 |
| discussion | 比较观点、证据和限制 | 可选 |
| qa | 解释、提问、回答及反馈 | 可选，不能代替必经验证 |
| knowledge-recording | 同时整理知识点与知识笔记 | 可选，保留未验证状态 |
| verification | 对照本轮目标验证真实理解 | 正常完成前必经，结果归问答记录 |
| framework-change | 改知识框架 | 当前禁用，未来独立确认流程 |
| profile-change | 改画像 | 当前禁用，未来独立确认流程 |

材料准备和规划说明是辅助指令，不额外增加可选行为。行为内部可多次调用工具，不强制相同教学顺序。

## 更新、来源与版本

材料由工具成功后登记；行为正式产物在确认保存后写入。learning-review 的 reason 由模型整理，是否达标与变化清单由代码核对正式验证和明确 plan_id。未关联的独立记录不按时间猜测归属。

同一次学习共享 study_id，revision 递增，新版通过 previous_plan_id 指向旧版；目标保持不变，旧规划和失败结果保留。当前使用 UUID 编号，不迁移现有标识。知识点唯一名称或别名可复用，不自动改写核心框架。

记录区分原文、用户表达与模型整理；保存真实对话、引文位置及未验证状态。结构正确与引用存在不等于内容正确，用户可以要求修订。

## 模型、程序和控制器

模型负责语义判断、澄清、规划、行为选择、讲解、提问、反馈和 reason。代码提供工具、限定材料范围、校验 Schema 和编号、保留真实回复、保存版本及管理状态。

总指令描述职责与边界，behavior 文档描述可选能力，工具 description 说明具体用途和参数。文件不会自动生效，由入口加载；调度由模型决定，权限、预算和结束条件由程序执行。

流程控制器管理等待、恢复、调用上限和阶段转换；日志与快照记录发生过什么，不替代正式学习笔记。统一入口不会自动代答，也不会无限循环调用。

## 当前产品边界

已接通统一终端和本地文件闭环。当前组合链路通过离线测试，真实 API 验证范围另见实现说明。没有自动修改画像/框架、通用网络研究或向量 RAG；复杂解析、语义判断和异常恢复仍有实际限制。
